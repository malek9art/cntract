# نظام إدارة عقود الموظفين والعهد والمستندات | شركة أبو حذيفة للصرافة والتحويلات

نظام إداري ومالي متكامل للموارد البشرية وإدارة العقود والأصول والعهد الوظيفية (الأجهزة، المعدات، المركبات) مع إصدار محاضر الاستلام والتسليم والإرجاع، وإدارة الرواتب (بالريال اليمني YER والريال السعودي SAR بشكل منفصل)، وتوليد وطباعة ملفات ومستندات PDF الرسمية عالية الجودة بهوية شركة **أبو حذيفة للصرافة والتحويلات**.

---

## 🌟 مميزات النظام الرئيسية

1. **يعمل مباشرة على GitHub Pages وبشكل Offline-First:**
   - مبني بالكامل باستخدام **HTML5 / CSS3 / Vanilla JavaScript ES6 Modules**.
   - لا يتطلب أي Backend أو Node.js أو عمليات Compile / Build.
   - تخزين بيانات محلي متين وعالي الأداء عبر **IndexedDB**.
   - مسارات نسبية متوافقة 100% مع GitHub Pages Root أو Project Subfolders.

2. **الهوية البصرية لشركة أبو حذيفة للصرافة والتحويلات:**
   - ألوان الهوية المستخرجة من الشعار: الكحلي الداكن المالي (`#0A1E3F`)، الأزرق الفيروزي (`#00B4D8` / `#0284C7`)، والذهبي الملكي (`#D97706`).
   - الخط الأساسي: **IBM Plex Sans Arabic** لجميع الواجهات والمستندات.
   - واجهة عربية أصيلة **RTL بالكامل** مع دعم الشاشات الكبيرة والجوال والأجهزة اللوحية.

3. **لوحة التحكم والإحصائيات (Dashboard):**
   - مؤشرات أداء فورية لعدد الموظفين، العقود النشطة، المنتهية، والقريبة من الانتهاء (تنبيهات 30 و60 و90 يوماً).
   - إحصائيات دقيقة للعهد المسلمة، المرتجعة، المتضررة، والمفقودة، والسيارات المسلمة.
   - كتل الرواتب الإجمالية منفصلة بالريال اليمني (YER) وبالريال السعودي (SAR).

4. **إدارة الموظفين والملف المتكامل (Employee 360° Profile):**
   - ملف شامل لكل موظف يحتوي على البيانات الشخصية، الوظيفية، والمالية (الراتب الأساسي، البدلات، الخصومات، الصافي).
   - عرض فوري للعقود المرتبطة، الأجهزة والعهد المسلمة، السيارات المخصصة، المحاضر، والمستندات المرفقة، وسجل العمليات.

5. **عقود العمل ومحرر البنود الـ 22 وقوالب العقود:**
   - 22 بنداً تعاقدياً معتمداً وقابلاً للتعديل، مع دعم إعادة الترتيب والتعطيل والتفعيل.
   - إدراج المتغيرات الديناميكية تلقائياً (`{{employee_name}}`، `{{salary}}`، `{{job_title}}`، `{{branch}}`، إلخ).
   - نظام الإصدارات (Contract Revisions): حفظ نسخ غير قابلة للتعديل عند تعديل العقود المعتمدة (v1.0 -> v1.1) مع الاحتفاظ بالأصل.
   - منع أرقام العقود المكررة والتحقق من صحة التواريخ.

6. **سجل العهد المركزي ومحاضر الاستلام والإرجاع:**
   - إدارة متكاملة لأجهزة الكمبيوتر، اللابتوبات، الهواتف، آلات الصرافة وعد النقد، الطابعات، أجهزة البصمة، والمفاتيح.
   - محضر استلام عهدة رسمي موثق بالتواقيع والختم والإقرار القانوني.
   - محضر إرجاع عهدة مع توثيق الأضرار والنواقص وبراءة الذمة.
   - منع تسليم العهدة نفسها لأكثر من موظف في نفس الوقت.

7. **إدارة السيارات والمركبات ونموذج الفحص الفني:**
   - تسجيل بيانات الهيكل، المحرك، الشاصي، ورقم اللوحة.
   - نموذج فحص فني تفاعلي (Checklist) للهيكل، الإطارات، الزجاج، التكييف، عداد الكيلومترات، ومستوى الوقود قبل التسليم وعند الإرجاع.

8. **الرواتب والبدلات ومسيرات الرواتب:**
   - فصل تام بين الريال اليمني (YER) والريال السعودي (SAR) دون أي تحويل تلقائي بين العملات.
   - طباعة قسائم الرواتب الفردية للموظفين مع تفقيط المبالغ باللغة العربية (Tafqeet).
   - طباعة كشف مسير الرواتب الشهري العام.

9. **الطباعة وتوليد مستندات PDF الاحترافية:**
   - مستندات A4 RTL رسمية مطابقة للمواصفات الحكومية والمصرفية.
   - ترويسة وشعار الشركة، الختم الرسمي المعتمد، جداول منظمة، وترقيم صفحات، وفواصل لمنع تداخل الصفحات.

10. **التقارير وسجل التدقيق والنسخ الاحتياطي:**
    - 10 تقارير تحليلية مع إمكانية التصفية والطباعة والتصدير.
    - سجل تدقيق محلي (Audit Log) يوثق كل عملية إدارية بالتاريخ والمستخدم.
    - تصدير واستعادة النسخة الاحتياطية بصيغة JSON مع فحص سلامة البيانات.

## 🚀 تعليمات رفع المشروع إلى GitHub Pages

1. قم بإنشاء مستودع جديد على حسابك في GitHub (مثل `cntract` أو `abuhudhayfah-system`).
2. ارفع كافة ملفات المشروع إلى الفرع الرئيسي `main`.
3. ادخل إلى إعدادات المستودع **Settings** &larr; **Pages**.
4. من قسم **Branch**، اختر `main` واضغط **Save**.
5. سيعمل التطبيق فوراً على الرابط المباشر:
   `https://<username>.github.io/<repository-name>/`
